# Python for AI Engineers - Week 1 Runnable Code

Each learning task is stored as an individual runnable file.

Filename format: `w1-d<day>-t<task>-<description>.py`

## Run a task

```bash
python w1-d1-t1-create-print-variables.py
```

Interactive scripts ask for input. Install the optional quality tools with:

```bash
python -m pip install black ruff
```

The Day 7 final project creates `portfolio-data.json` beside the script when run.
